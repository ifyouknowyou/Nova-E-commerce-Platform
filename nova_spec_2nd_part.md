============================================================
PROJECT GOAL
============================================================

Build a modern, premium, production-ready multi-vendor e-commerce platform with an original design and architecture.

The platform must support:

• Customers
• Sellers
• Administrators

The application must be responsive, secure, scalable, and maintainable.

============================================================
USER ROLES
============================================================

There are only three roles.

1. Customer

2. Seller

3. Administrator

Each role must have its own dashboard and permissions.

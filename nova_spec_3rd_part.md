DESIGN PHILOSOPHY
============================================================

The application must feel like a premium modern SaaS + enterprise e-commerce platform.

The UI should prioritize:

• Simplicity
• Consistency
• Professionalism
• Speed
• Accessibility
• Readability
• Visual hierarchy
• User trust

Never copy Amazon or any other website.

Create an original design language.
